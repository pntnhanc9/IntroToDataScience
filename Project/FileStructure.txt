CHI TIẾT NỘI DUNG TỪNG FILE
1. File 01_Data_Cleaning.ipynb (Giai đoạn 1 & 2)
Mục tiêu: Biến "Rác" thành "Vàng".

Đầu vào: Các file trong data/raw/.

Nội dung chính:

Load và Merge dữ liệu (Gộp 4 nguồn).

Standardization (Chuẩn hóa ngày, giá tiền).

Feature Extraction (Regex tách quận, huyện, tiện ích, boolean...).

Geocoding (Chạy cái này ở đây vì nó lâu, chạy xong lưu lại ngay).

Xử lý Missing Values & Outliers.

Đầu ra quan trọng: Xuất ra file data/processed/clean_data_final.csv.

Lưu ý: File này chạy 1 lần là xong. Sau này train model không cần chạy lại file này nữa.

2. File 02_EDA_Insight.ipynb (Giai đoạn 3)
Mục tiêu: Kể câu chuyện về dữ liệu (Data Storytelling).

Đầu vào: data/processed/clean_data_final.csv.

Nội dung chính:

Load dữ liệu sạch.

Vẽ biểu đồ phân phối Giá (Histogram).

Vẽ bản đồ nhiệt (Heatmap) dựa trên Lat/Long (Chứng minh khu vực nào đắt).

Phân tích tương quan: "Nhà có nội thất đắt hơn bao nhiêu?".

Kết luận của file: Trả lời câu hỏi "Tại sao tôi chọn những features này để đưa vào Model?".

3. File 03_Modeling.ipynb (Giai đoạn 4, 5, 6, 7)
Mục tiêu: Xây dựng cỗ máy dự đoán và giải thích.

Đầu vào: data/processed/clean_data_final.csv.

Nội dung chính:

Split Data: Chia Train/Test ngay đầu file.

Feature Engineering:

Tại đây bạn code các hàm Target Transformation, Encoding, Scaling, Polynomial.

Mẹo: Dùng sklearn.pipeline.Pipeline để gói gọn các bước này.

Training: Chạy thử nhiều model (Linear, Random Forest, XGBoost).

Evaluation: So sánh RMSE, R2 Score.

SHAP Analysis: Vẽ biểu đồ giải thích tại sao căn nhà đó giá 5 tỷ.

Đầu ra: Lưu model tốt nhất vào models/best_model.pkl.
